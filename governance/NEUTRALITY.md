# Neutrality Statement (DRAFT)

TrustMCP is an **open standard**, not a product of any single company.

1. **Open license.** The specification, JSON Schemas, SDK, MCP server, and
   conformance suite are Apache-2.0 — anyone may implement, host, fork, or extend the
   standard. The reference apps are FSL-1.1-ALv2, converting to Apache-2.0 two years
   after each release.

2. **No verdict in the network.** The network shares raw, current evidence and
   verifies identity + the mark. It never scores, rates, ranks, or certifies vendor
   quality. Each customer computes its own verdict locally and never sends it back.

3. **No preferential access.** No member — including any founding company or network
   operator — gets privileged access to another member's evidence. Access is governed
   solely by the publishing vendor's grants.

4. **Portability.** Profiles are plain JSON behind a documented API. A vendor can move
   between accredited operators; a consumer can switch tools. There is no lock-in to
   any one implementation.

5. **Multiple implementations encouraged.** The reference network and MCP server are
   starting points. Competing, conformant implementations are welcome and expected.

6. **Governance in the open.** Spec changes happen via public proposals and review.

If any practice appears to violate this statement, raise it publicly in the repo or
with the Board.
